# Web Zelora — React + Vite

## Requirements
Install Node.js LTS before starting.

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Assets
- Put the hero video at `public/video/web_zelora_video.mp4`.
- Put any additional images in `public/images/` and reference them with `/images/filename.ext`.

## Contact form
The original form's front-end validation has been converted to React state. It currently validates the details in the browser; connect it to your email service, WhatsApp flow, or backend to receive submissions.
